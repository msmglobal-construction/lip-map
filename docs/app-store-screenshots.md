# Lip Map — Screenshot checklist

Capture on a physical iPhone or Simulator. Prefer **6.7"** (e.g. iPhone 16 Pro Max) and **6.1"** sizes ASC currently requires. Portrait only.

Do **not** overlay ZYN branding. Optional light caption text is fine (“Tap Tucked”, “Unique places win”).

## Required storyboards (capture these screens)

| # | Screen | How to get there | What reviewers / shoppers should see |
|---|---|---|---|
| 1 | **Home / Tucked** | Home tab | Giant **Tucked** button, today + lifetime counts. Clean first impression. |
| 2 | **Map** | After 2–4 tucks → Map tab | Several pins, one callout open (flavor/place if available). |
| 3 | **Badges** | Badges tab | Grid with a mix of locked + unlocked (e.g. First Lip Pillow). |
| 4 | **Friends leaderboard** | Friends tab | Leaderboard section first (unique places this week). Invite controls OK below fold or cropped. |
| 5 | **Paywall** | Trigger hard gate or present Full Map | **Full Map**, yearly ($9.99 · trial) + weekly ($0.99), Restore. No ZYN in titles. |
| 6 | **Dashboard** | Home → **Your map stats** chip/sheet | Joke stats: totals, heat, top places/flavors — not quit/wellness metrics. |

## Nice-to-have (if ASC slot count allows)

- **States** grid (Home → States) with a few filled states  
- **History** with swipe-delete hint (optional; don’t clutter the main set)  
- Flavor picker sheet after Tucked (optional)

## Prep data before capture

1. Allow location; tuck in a few distinct places (or simulator custom locations).
2. Tag at least two flavors so Map/Dashboard look alive.
3. Accept a friend or seed local friend data so the leaderboard isn’t empty (or screenshot with you alone ranked #1 — acceptable).
4. Unlock 1–2 badges for visual variety.
5. For paywall shot: use StoreKit config or an account under the free gate.

## Export tips

- Status bar clean (full signal/battery) via Simulator → Features if needed  
- No debug banners / “Personal Team” watermarks in final marketing shots  
- Same wallpaper/theme across the set  
- Save PNGs named like `lipmap-67-01-home.png`, `lipmap-67-02-map.png`, …

## Upload

App Store Connect → Lip Map → version → **Previews and Screenshots** → drag in per device size.
